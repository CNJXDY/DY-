GitHub入门指南：从注册到提交第一个Pull Request

2026-09-24 · 624字 · 开发工具

GitHub是全球最大的程序员社区，也是学习编程最好的地方。但它对新手来说有点复杂，今天写一篇零基础教程。

第一步：注册GitHub账号。去 github.com 注册，起个好记的用户名（以后可以当作品牌）。

第二步：安装Git。Windows去 git-scm.com 下载安装；Mac用终端输入 git --version 会提示安装；Linux用 apt install git 或 brew install git。

第三步：配置Git。打开终端，输入 git config --global user.name '你的名字' 和 git config --global user.email '你的邮箱'。

第四步：创建仓库。在GitHub网站上点右上角+号，选New repository，起个名字，选Public，点Create。

第五步：克隆仓库到本地。git clone 你的仓库地址，然后就可以在本地编辑代码了。

第六步：提交代码。git add .（添加所有修改）、git commit -m '描述'（提交）、git push（推送到GitHub）。

第七步：参与开源项目。在别人的仓库里点Fork（复制到自己账号），修改后提交Pull Request，等待项目作者审核合并。

GitHub不止是存代码的地方，你的GitHub主页就是你的技术名片。好好维护，对找工作很有帮助。

一开始可能会觉得Git很难，但坚持用一个星期，你会发现离不开它。
