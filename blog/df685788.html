不用Postman也能测试API：5个轻量级替代方案

2026-09-20 · 545字 · 开发工具

Postman 是API测试的标配，但很多人不知道的是，它现在已经变得非常臃肿了。启动慢、占内存大、还要注册账号。

如果你只是想偶尔测试一下API，完全不需要装 Postman。下面推荐几个轻量级替代方案。

VS Code 的 REST Client 插件：在 VS Code 里直接写 .http 文件，发送请求，查看响应。不需要切换窗口，开发体验极佳。

curl 命令行：最经典的HTTP客户端，几乎所有系统都自带。虽然界面不友好，但功能强大，可以写脚本批量测试。

httpie：curl 的升级版，语法更友好，输出自动高亮。支持 JSON、表单、文件上传等。pip install httpie 就能装。

Insomnia：开源免费的API客户端，界面简洁，支持 GraphQL、gRPC。比 Postman 轻量很多。

浏览器自带的开发者工具：Chrome 和 Edge 的 Network 面板可以直接查看请求和响应，F12 就能打开。

选择建议：如果你用 VS Code，首选 REST Client 插件；如果喜欢命令行，httpie 比 curl 更友好；如果想要图形界面，Insomnia 是个不错的选择。

轻量级工具的好处是：不占资源、启动快、不需要账号。对于日常开发来说，已经足够了。
